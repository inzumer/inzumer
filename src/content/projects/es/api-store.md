Un backend completo en NestJS sobre MongoDB, con foco en una arquitectura limpia, cobertura de
pruebas con Jest, automatización de CI/CD con GitHub Actions y observabilidad con Sentry.

Muestra cómo estructurar un backend escalable: módulos, manejo de errores y pruebas de integración.
Cada pull request se valida sola con linters, auditorías y umbrales de cobertura.
